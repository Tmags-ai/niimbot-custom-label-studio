Printer & Setup

Open Printer & Setup

Connect the printer

  1. Load the label roll, turn on the printer, and open the Studio in Chrome or Edge on Windows. Use the published HTTPS page or localhost.
  2. Bluetooth: Click Connect Bluetooth, select the printer in the browser’s device chooser, and connect. If it is missing, check that Bluetooth is on, the printer is nearby, and another app has released its connection. Open the chooser again. Use Disconnect when you need to release the Bluetooth connection.
  3. USB for the M2-H: Plug in a USB data cable, click Connect USB (M2-H), and choose the printer’s serial port. Confirm the USB indicator says connected. If no port appears, try a different data cable or port and close other apps that may be using the connection. Use Disconnect USB to release it.
  4. Check the connection status and detected model before printing. Experimental printer test mode allows one label per job on an unverified printer. Batch and multi-ribbon printing require a verified printer profile.

Read diagnostics

Read RFID status
Reads the connected Bluetooth printer’s consumable response when supported. Depending on firmware, it can show fields such as used paper, capacity, and print limit. Compare readings before and after a single test print. The app may report a field as unavailable or its meaning as unverified.
Read USB counters (read-only)
Reads diagnostic values via the M2-H USB connection. Check the USB status area for the result.
Refresh diagnostics
Updates the displayed printer, available roll-counter reading, change since the previous reading, and Studio session count.
Physical labels used per print job
Enter an estimate for tracking and compare it with the physical output. The session count tracks successful print commands, while one command can request multiple labels. RFID reads leave the roll data intact.
Reset session count
Clears the Studio’s local tracking for a fresh comparison.

Set the label size and print quality

  1. Choose a Label size preset matching the roll packaging. For another size choose Custom size and enter width and length in millimeters. The M2-H custom controls accept 20–50 mm width and 8–240 mm length. Test long labels on the actual printer.
  2. Set Orientation in the printer banner to Landscape or Portrait. The selected size and orientation carry across tabs. Use the circle preset when you want a circular print mask.
  3. Start with Print density at 3. For USB, the USB print sharpness threshold defaults to 114. Lower it when fine letters look heavy or increase it when light details disappear. Change one setting at a time and compare test labels.
  4. For Bluetooth, start with Paced (safer). Automatic lets the driver choose. Acknowledged is slower and Fast is experimental.

Calibrate the physical print

Artwork size (%) and Horizontal/Vertical shift (mm) apply to the print output. Start with the M2-H defaults of 100%, 0 mm horizontal and −0.5 mm vertical. Print one test after each adjustment. Use Reset print alignment to restore those defaults.

If the top edge has a gap, try a single print at −1.0 mm vertical shift and compare it with Download exact print-ready PNG in Custom Label. If the exported artwork reaches the top but the physical print still has a white strip, the leading edge may be outside the printable area.

Custom Label

Open Custom Label

Set up the canvas

Use the shared Label setup and Orientation controls to match the roll. Use Rotation for whole-design print rotation. Use Layer rotation (degrees) to turn just one selected item. The live preview shows the printable label. Artwork that extends beyond its edge is clipped.

Zoom the live preview

Use + and − above the live preview to zoom from 25% to 300%. Zoom in to inspect small text or work on a portrait label. If part of the label extends beyond the preview, scroll inside it to reach that area. Click Fit to bring the full label back into view. The zoom controls only change the on-screen view. Printed and exported artwork keeps its original size.

Add, select, and arrange layers

  1. Use + Text, + QR, + Image, or a line or shape button to add an item. Each item has its own position, size, rotation, and ribbon assignment.
  2. Click an item in the preview or select it in Layers below the live preview. Use the arrows in the layer list to change which objects cover others. Put a background shape below the text or images it should sit behind.
  3. Drag the item, or open Advanced positioning and size to enter exact X (%) and Y (%) values. Use arrow keys for small nudges. Drag a resize handle or enter Width (%) and Height (%). Keep aspect ratio checked for proportional resizing. Use Reset selected item size & aspect ratio to recover the item’s starting proportions and size.
  4. Use Center horizontally, Center vertically, or Center both to center the visible artwork. For drag alignment, use the label-center snap controls or enable Snap to another layer and choose a target under Align with layer.
  5. Use Duplicate to reuse a styled item or Delete to remove the selection. Clear layers clears the custom design.

Name layers and undo edits

Select a layer in the preview or in Layers. Its row is highlighted in the list and its bounds appear on the preview. Enter an optional Layer name such as “Logo” or “Lot number.” Names appear in the editor and are saved in editable projects.

Use Undo and Redo above the preview to step through Custom Label layer edits. When you are outside a text field, press Ctrl+Z to undo or Ctrl+Shift+Z to redo. A drag is one edit. Importing an editable project starts a fresh edit history.

Adjust each layer

Text
Type in Selected content / QR value. Press Enter for a new line. Choose the font, point size, and bold setting. Text alignment offers Left, Center, Right, and Justify. Justify spreads words across eligible lines and leaves the final line left-aligned. Widen or enlarge the box if text scales down too far. Use Auto-fit selection to text/image to trim unused space around text. Import a custom font with a supported TTF, OTF, WOFF, or WOFF2 file.
QR code
Enter the URL or value in Selected content / QR value. Give the code and its surrounding blank space enough room, then scan a test print with a phone.
Images
Choose + Image and select an image file. Resize it with aspect ratio locked when you want to preserve proportions. For white artwork on a transparent PNG, select Use light pixels as printable ink as appropriate and check the preview before printing.
Lines and shapes
Select a shape and choose Shape fill for outline-only or solid artwork. Set the outline style and thickness in millimeters. Use corner radius where supported.
Ink and ribbon
Ribbon / layer color assigns the object to a physical ribbon pass. Object color, Shape fill, and Invert black / white affect how the object renders. For white lettering in a monochrome design, place it above a solid dark background and preview the result.

Print in black and white

  1. Choose Black & White under Print mode. The panel reads Print this Custom Label Studio design.
  2. Use a black ribbon on white labels. The Studio renders your layers together in one pass. Set Number of identical copies from 1 to 100.
  3. Click Print Label, confirm the quantity, and inspect one physical label before making more. Use Download exact print-ready PNG to inspect the calibrated artwork.

Print with multiple ribbons

  1. Select each layer and assign its Ribbon / layer color. Black, white, gold, red, blue, and green are available.
  2. Choose Multi-Ribbon under Print mode to show Multi-ribbon color printing. Set Preview to see all color assignments together or isolate one pass. The colors on screen approximate the ribbons.
  3. Use Start guided printing to step through assigned colors, or choose a color manually under Ribbon installed / print color. Install that ribbon, enter Copies per color pass, and click Print selected ribbon color.
  4. Inspect the pass. Rewind and precisely realign the same physical labels before changing ribbons. Keep the same quantity and label order for every pass. In the guide, choose Next color / step only after checking the physical output. Repeat for the remaining colors.
  5. Test with one spare label first. When an edge or alignment looks off, choose the relevant ribbon and download its print-ready PNG for comparison.

Use Vial Calc

  1. In Custom Label, open Vial Calc below the layer buttons.
  2. Enter Vial amount (mg) and Final vial volume (mL). Use the total volume of the finished solution. The calculator divides the amount by the final volume to show the concentration in mg/mL.
  3. To show a conversion, enter a Target amount (mg, optional). Vial Calc displays the equivalent volume on the U-100 scale, which uses 100 markings per mL. The target must be positive and within the vial amount. If the conversion exceeds 100 units, the calculator flags it and leaves the conversion layer blank.
  4. Click Add concentration layer or Add U-100 conversion layer for one result, or Add both to label for both. Use Select layer beside a linked result to jump to its editing controls. Move, resize, and style the results like other text layers. The calculator shows (U-100) beside the conversion, and the linked layer uses the shorter mg = units format.
  5. Edit the numbers in Vial Calc to update any linked layers. Their position and styling stay in place. An invalid input clears the affected layer text until the result is valid again.
  6. Use Export editable project to save the calculator inputs and linked layers together. Reopen the JSON with Import project to change the numbers later.

Build and print a protocol schedule

Protocol is an optional Vial Calc tool for composing a multi-stage, editable text schedule on a label. It formats amounts and durations you enter; it does not recommend or validate those values.

  1. Open Custom Label → Vial Calc and check Enable Protocol. The stage fields appear below the concentration and U-100 conversion tools.
  2. For each stage you want to show, enter Stage amount (mg) and Stage duration (weeks). You can enter up to four stages in order; leave unused stage rows completely blank. A used stage needs a positive amount and duration.
  3. Read the live Protocol result. Without a valid vial amount and final volume it lists each stage's amount and weeks. When those vial fields are valid, the Studio can append a per-stage U-100 conversion. A stage above the vial amount or exceeding 100 U-100 units produces a warning and shows its mg amount without an invalid units figure.
  4. Click Add protocol layer to place the multi-line schedule on your label. Adjust the layer's font, alignment, size, position, and rotation using the regular editor controls. Use Select layer in the linked-layer area to return to it.
  5. Edit any stage's amount or duration to update the linked text automatically. Unchecking Enable Protocol clears the schedule text from the linked layer but retains stage inputs; checking it again restores the valid schedule.
  6. Use Export editable project to save the protocol values and linked layer in a JSON file. Use Import project later to reopen and edit the design.

Important: Protocol is a formatting aid only. It does not prescribe, validate, or recommend a dosing or treatment schedule. Verify the figures and intended use independently before printing or relying on a label.

Save and reopen an editable design

Use Export editable project to save the design as JSON, including editable layers and any imported background or custom fonts. Use Import project to reopen it. Export your current design before replacing it with another project. A PNG is useful for inspecting or sharing the finished artwork, while JSON lets you edit the individual layers again.

Import Label

Open Import Label

Bring in artwork from Canva or another design app

  1. Export at the physical label’s proportions. In Canva, choose Share → Download → PNG or PDF Print. The Studio accepts PNG, JPG/JPEG, WebP, and PDF. PDF import uses the first page and needs internet access for the PDF renderer.
  2. Set the shared label size and orientation to match your roll. In Import Label, select the file under Upload Canva export / preconfigured label and check the live preview.
  3. Choose Artwork fit. Fit entire design (no cropping) preserves the complete artwork and can leave margins. Fill label (crop edges if necessary) fills the preview while preserving proportions. Stretch to label size fills it by adjusting width and height independently.
  4. To position artwork yourself, select it in the preview, drag it, or drag a corner to resize. Keep aspect ratio checked to preserve its shape. Use Auto-fit imported label to page or Reset imported label size & aspect ratio to recover a fitted layout. Use Remove imported label to clear the background.
  5. Set Number of identical copies (1–100), click Print imported label copies, and confirm. This workflow sends monochrome output. Print one test before increasing the count.

You can add editable layers on top of an imported label.

Leave the artwork loaded, switch to Custom Label, and add text, QR codes, shapes, or images. Adjust the new layers in the preview. To print the combined design, return to Import Label and use Print imported label copies. To reopen the combined design later, use Export editable project in Custom Label.

Quick Template

Open Quick Template
  1. Set the shared label size and orientation. If a custom design or imported background is loaded, export it as an editable project first, then clear those layers or remove the imported background.
  2. Check Show quick template (headline, details and separator) to preview the template. Type the main line under Headline.
  3. Enter the remaining information under Details, one field per line. For example, put sample ID, lot number, and date on separate lines. Check the preview on small labels and shorten the text or remove lines if needed.
  4. Use Show separator line to add or remove the divider. Use Logo / label image (optional) to add an image. Check legibility at the actual label size.
  5. Enter Copies to print (1–100), click Print quick template, and confirm. Start with a single copy. If you were previewing a CSV row, return to Batch Printing and click Restore design before printing the quick template.

Batch Printing

Open Batch Printing

Use one CSV data row per label design. The Studio fills text and QR placeholders from that row and prints the requested number of copies.

Prepare the CSV

  1. Click Download CSV template and open it in Excel or Google Sheets. Keep one header row with unique, nonempty column names. Add one row per product, sample, or lot.
  2. Use headers suited to your label, such as Product, Strength, LOT, or URL. Optionally add Copies and enter a whole number from 1 to 100 for an individual row. A blank or missing Copies value uses the app’s Default copies per CSV row.
  3. Export as a comma-separated CSV. Preserve leading zeros in ID or lot fields by keeping those cells as text in your spreadsheet. Open the exported CSV and check any values that must retain their exact formatting.
Product,Strength,LOT,Copies
Product A,10 mg,LOT-001,1
Product B,20 mg,LOT-002,2

This example prints one label for Product A and two for Product B.

Build a reusable label

  1. In Custom Label, choose the roll size and build a simple black-and-white layout, or let the CSV upload generate editable fields when the current design has no matching placeholders. Clear any imported background you do not want in the batch.
  2. In a text layer, enter {{Product}} or combine fixed text with variable fields, such as Lot: {{LOT}}. A QR layer can use {{URL}} if your CSV has a URL column, or embed a field in a larger value such as https://example.com/lot/{{LOT}}.
  3. Match header spelling and capitalization. Static shapes and images stay in place. Leave enough room for the longest names and codes. If automatic fields overlap existing artwork, use Restore design and move or delete those layers in Custom Label.

Upload and preview

  1. Go to Batch Printing, set Default copies per CSV row, and select your CSV under Batch CSV file. The Studio lists the row count and detected columns, displays the calculated label total, and previews the first data row.
  2. Enter a row number and click Preview row. Row 1 is the first data row after the header. Check rows with long values, blank fields, or QR codes. If a placeholder remains visible, compare it with the column name shown after upload.
  3. Click Restore design before editing or exporting the reusable template. It restores placeholder text and QR values after a preview.

Print, stop, and recover

  1. Connect a verified printer over Bluetooth for the batch workflow and make sure the roll has enough labels. For a test run, set Rows to print to 1 and make sure that row’s copy count is 1. The field prints the first N data rows. Leave it blank for all rows.
  2. Review the row count, label total, and any unmatched placeholders beside Print batch. Then click Print batch and read the confirmation prompt for the number of rows and total labels. Inspect the test print and scan any QR code before committing to the full run.
  3. Watch the progress status. Stop after current label requests a stop after the current print job finishes, so the remaining copies in that job may still print.
  4. If interrupted, count the labels physically printed before restarting. To resume from a later row, make a fresh CSV with the same header and only the remaining rows or copies. Upload it, preview the first remaining row, and confirm the new total before printing.
  5. After the run, review the completion status and check the physical output. The app restores the original placeholder design when the run ends.
